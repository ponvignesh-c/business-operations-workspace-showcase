# Public Repository Boundaries

This showcase was prepared for public sharing and professional discussion.

## Removed before publication

- All environment variables, secret keys, database passwords, and email credentials.
- All business identity, local data, customer/supplier/staff records, and financial history.
- All database files, exports, backups, and deployment addresses.
- The complete private application source and operational configuration.

## Included

- Feature design and workflow documentation.
- A synthetic SVG interface preview containing fictional values and no real records.
- A small illustrative code sample that contains no private production logic.
- Container, runtime, security, and deployment-readiness documentation.

## Important

The private repository remains the working-code home. This public repository is intentionally non-deployable and should not be used to operate a business.
